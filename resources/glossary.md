# 詞彙表

跳著讀這本書的人，這一頁是你的入口。每個詞一句定義，加上它在哪裡展開。

七章之間有些詞長得很像卻不是同一件事，那幾組另外標了 。分組依章序，共八組。

---

## 一、這個工具在做什麼（第 1 章）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **機率接龍** | 它實際做的運算：給定目前為止的所有文字，算出下一個字最可能是什麼，接上去，再算下一個 | 1.1 |
| **幻覺** | 生成出不存在或不正確的內容。**這個詞取得不好**，它暗示是一種故障，但生成對的與生成錯的走的是同一條路徑 | 1.2 |
| **拼裝文獻** | 每個零件都是真的、組合起來卻不存在的引用：真作者、真期刊、合理年份、像樣標題。它是 Vibe Citing（氛圍引用）的其中一型，不等於 Vibe Citing 全部 | 1.2 |
| **錯誤歸屬** | 把 A 理論的術語安到 B 學者頭上。難抓是因為它在學理上讀起來是通的 | 1.2 |
| **虛假精確的數字** | 生成出來的 α、N、r 值。危險在於**數字看起來就不像可以被編造的東西** | 1.2 |
| **風險判準** | 可偵測性（越低越危險）× 不可逆性（越高越危險）。**與任務難度無關** | 4.2 |

## 二、術語基座（第 1 章 1.1，全書用語在此定錨）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **提示詞**（Prompt） | 你送進去的那段文字。它不是「指令」，是接龍的起頭 | 1.1 |
| **脈絡（context）** | 模型生成下一個字時，實際看得到的所有文字。**脈絡以外的東西對它不存在** | 1.1 |
| **詞元**（Token） | 模型處理文字的最小單位，也是計量單位：用量、長度上限、費用都以它計 | 1.1 |
| **上下文視窗**（Context window） | 一次生成能容納的脈絡上限。**具體數字隨版本變動，但上限永遠存在** | 1.1 定義／3.2 展開 |

## 三、把話說清楚（第 2 章）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **七元素** | Role／Task／Context／Format（任務骨架）＋Product／Process／Performance（協作深度）。共同機制是**補脈絡** | 2.2 |
| **Process（過程）** | 七元素裡最少人用、效果最大的一個。寫法只有一句：「開始之前，先問我三個你還不確定的資訊」 | 2.2 |
| **Performance（表現）** | 指定它以什麼身分表現（教練／挑戰者／審查者）。決定的是**誰在思考** | 2.2 |
| **4D 框架** | Delegation（該不該交出去）／Description（講明白了嗎）／Discernment（夠好嗎）／Diligence（留紀錄了嗎）。七元素只涵蓋 Description | 2.3 |
| **雙迴圈** | 4D 的兩個迴圈週期不同：內圈（描述、辨別）一次對話往返，外圈（委派、謹慎）一個任務或一篇論文 | 2.3 |

**七元素 ≠ AI 素養。** 七元素全部落在 Description 一個 D 上，也就是 4D 的四分之一。把 AI 素養等同於會寫提示詞，漏掉的正是另外四分之三。

## 四、工作環境與建造（第 3 章）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **四個入口** | 一個 Claude，四個入口（Chat／Projects／Cowork／Code）。差別不在功能，在**責任分配與出事代價** | 3.1 |
| **Skill** | 把重複的做法固定下來的一份說明文件。**內容只在被用到時才載入**，所以放再多參考資料平時也不佔脈絡 | 3.3–3.4 |
| **Agent** | 能自己決定步驟、連續執行的模式。自動化程度越高，**你驗收的責任越大，不是越小** | 3.3 |

**Prompt、Skill、Agent 是包含關係，不是替代關係。** 三者是層級遞進，不是三選一。

## 五、記憶與文獻蒐集（第 4 章）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **專案記憶** | 這個研究的決定與理由。載體是專案說明檔＋決策日誌。做完就凍結 | 1.2 |
| **知識記憶** | 你讀過的東西、想通的概念。載體是 Obsidian 知識庫。跨專案、跨年度累積 | 1.2 |
| **決策日誌** | 一行一則：日期｜決定｜理由。**沒寫理由的日誌等於沒寫**，因為未來的你要推翻的正是理由 | 1.3 |
| **vault** | Obsidian 存放筆記的資料夾，本書的「知識庫」即指它 | 1.3 |
| **糾正迴圈** | 筆記產出後針對推錯的欄位下一句修正，看它改不改得對。真實使用中每一篇都要做 | 2.1 |
| **四種筆記** | 文獻（這篇說了什麼）／概念（我的理解）／靈感（想做什麼）／技術（怎麼做）。**概念筆記的數量比文獻筆記更能反映你的進展** | 4.4 |
| **研究取向** | 量化／質性／混合方法。由**研究問題的性質**決定，不由你比較會哪一種決定 | 4.1 |
| **世界觀** | 你相信什麼算證據：後實證／建構／轉化型／實用主義。它決定你覺得「嚴謹」是什麼 | 4.1 |
| **五維度評分** | 理論缺口／方法設計／樣本可行／測量嚴謹／實務貢獻，各 1–5 分。**分數本身不重要，分數帶對應的動作才重要**；15–20 分代表評分沒有鑑別力 | 4.1 |
| **驗證層級** | 你讀到什麼程度：全文逐字／摘要／僅書目。**它決定這一筆能撐多重的主張** | 4.5 |

**「AI 的記憶」與「你的兩種記憶」不是同一件事。** 官方文件講的是它那一端怎麼保存指令與學習；本書 1.2 講的是**你自己**要建的東西。兩者接得起來：你的專案記憶正是要寫進它讀得到的地方。

## 六、查證與綜整（第 5 章）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **最小查證三步** | 第 1 章的簡化版：DOI 解析得開嗎／作者真寫過這主題嗎／卷期年份對得上嗎 | 1.4 |
| **四步核實** | 完整版：DOI 指向該篇／標題交叉比對／**期刊真實性與掠奪性判別**／**作者名單與年份逐欄核對**。後兩步是三步版沒有的 | 5.1 |
| **掠奪性期刊** | 收錢就登、缺乏品質把關的期刊。引用它不算造假，但在審查階段一樣是傷 | 5.1 |
| **三種假綜整** | 編年式（按年份排的清單）／貼標籤式（分完派就沒有然後了）／AI 一鍵摘要式（**給你的是二十篇的平均值，不是你的立場**） | 5.3 |
| **容器**（歸櫃） | 每一句主張開一個容器，把筆記拆成證據片段丟進去。**空的容器就是研究缺口，或該放棄的主張** | 5.3 |

⚠️ **四步驗的是「存在」，不是「詮釋」。** 一篇真實存在的論文，完全可能沒有說你以為它說的話。詮釋那一層只能自己讀，沒有任何工具幫得上。

## 七、撰寫與修稿（第 6–7 章）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **寫作模式鏈** | plan → outline → draft → revise → abstract（＋revision-coach）。價值是**一次只想一件事** | 6.3 |
| **材料缺口**（MATERIAL GAP） | 它標記「這裡需要引用但你沒給我素材」。**標記出現一定要處理，沒出現不代表沒問題** | 6.3 |
| **修稿三輪** | 邏輯 → 去 AI 腔 → 格式，同一個對話裡跑完。格式放最後，因為前兩輪會大幅改動內容 | 7.1 |
| **AI 腔** | 空泛修飾詞、句長完全一致、拿掉也不影響段落的句子。去它不是為了規避偵測，是因為那樣的文字本身就比較差 | 7.1 |
| **保護片段** | 改寫之前先鎖住的五類：數字與統計、構念與術語、引用與歸屬、引號原文、版本識別。**潤稿的職掌正好對著這張清單開火** | 7.1 |
| **逆向大綱** | 只讀每段第一句、抄成清單，看它自己讀不讀得通。抓結構問題比通讀有效，因為通讀時你會被好句子安撫 | 7.2 |
| **主張與證據對照** | 每個實質主張逐條標出證據在哪一段哪張表。標不出來的就是空的；**摘要與引言裡標不出來的最嚴重** | 7.2 |
| **必改／該改／可改** | 自審清單的三個等級。分級不是描述問題多嚴重，是**決定修訂順序**——沒有分級的清單會讓人從最好改的開始改 | 7.2／附錄 I-0 |
| **收斂門檻** | 判斷自審跑完了沒的三個條件：必改歸零、該改 ≤2、AI 腔殘留 ≤1。**連續兩輪零進展也要強制結束** | 附錄 I-8 |
| **限制陳述的主詞** | 限制那一節該用「證據」當主詞，不是「本研究」。⚠️ 主詞放在自己身上讀起來像替結果打折 | 附錄 I-5 |
| **爆炸半徑** | 一處改動要沿四個方向追連帶：上游前提、下游實作、詮釋回扣、摘要鏡像。**追出「零連帶」代表沒有真的追** | 7.3 |
| **讓步稽核** | 專查「哪裡讓太多」的反向檢查：貢獻稀釋／過度刪除／方法投降／限制通膨／文獻塞入 | 7.3 |
| **答辯測驗** | 改完之後問自己四題（統計選擇、刪改判準、限制邏輯、逐條對應）。**確認的是作者就緒，不是稿件就緒** | 7.3 |

**「必改」與拒稿標準不是同一件事。** 必改是**你自己**掃出來、送出去之前要清掉的；拒稿標準（附錄 I-6）是**別人**用來判你出局的。前者你控制得了，後者你只能減少命中面積。

## 八、責任與誠信（貫穿全書）

| 詞 | 一句話 | 定義於 |
|---|---|---|
| **副駕駛** | 全書的核心比喻。副駕駛的價值不在他能飛，在於**他讓機長騰出注意力去處理只有機長能處理的事** | 前言／7.9 |
| **〈責任落點〉** | 每章末的固定小框，回答「這一章的責任落在誰身上」。七章收攏成一張表在 7.4 | 各章章末 |
| **單一判準** | 全書所有委派決定的同一個問法：**如果它做錯了，我看得出來嗎？** 看不出來的不能交 | 7.4 |
| **使用聲明** | 說明你怎麼用 AI 的紀錄。價值在**能不能被查證**，不在長度 | 1.4 三行版／7.4 完整版 |
| **揭露 vs 引用** | 揭露＝說明你怎麼用（幾乎一定要做）；引用＝把某次對話當成來源（只在那段對話本身是證據時）。**後果不同**：格式錯是編輯層問題，揭露不足是誠信層問題 | 附錄 D-3.5 |
| **去識別化** | 資料進入任何對話之前先移除可辨識資訊。判準是「這段內容能不能反推到特定的人」，不是「這算不算敏感資料」 | 7.4 |

## 怎麼用這一頁

- **跳著讀**：先查你不認識的詞，再跳到「定義於」那一節
- **課堂上**：學生問「這跟那個有什麼不一樣」的時候，多半就是 那幾組
- **複習**：把八組的第一欄遮起來，看著定義說出詞

**這一頁只給定義，不給操作。** 怎麼做在正文，介面步驟在附錄 A。
