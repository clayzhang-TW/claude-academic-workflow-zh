## 這本書在處理什麼

五件事，你大概都遇過：

> **文獻是個無底洞。** 第一天搜到四十篇，第五天發現有一整條你完全沒注意到的脈絡，下面又有八十篇。最後停下來的理由不是「讀夠了」，是「沒時間了」。
>
> **寫到一半失去方向。** 筆記做了三十份，每一份都很紮實。然後你打開空白文件，游標閃爍，寫不出第一句。
>
> **引用焦慮。** 改到第七稿，你已經記不清第三頁那筆引用是哪來的。要查的有六十幾筆，截止日在後天。
>
> **沒有人幫你審。** 你希望有人在送出去之前看一眼。但指導教授很忙，同儕在趕自己的稿，而你看這份稿子已經看到什麼都看不出來。
>
> **格式地獄。** 投稿前一晚你在改參考文獻的標點。這件事跟研究品質無關，但它會花掉你三個小時，而且下一篇還要再來一次。

這五件的共同點是流程太長、太碎、太孤獨。你在第八步已經忘記第二步做過什麼決定；每一段之間都有摩擦成本，而那些成本不會出現在任何一份研究計畫的時程表裡。

## 它不教「AI 有哪些功能」

整本書只有一個判準：**如果它做錯了，我看得出來嗎？**

七章各用一種方式回答它。所以書裡花很多篇幅在講它會在哪裡出錯、以及一份看起來完整的產出可以錯得多安靜。第 2 章有一節要求你先讓它騙你一次，親手抓到那一筆之後才准往下讀。

## 七章是一條工作流

![全書工作流地圖](resources/figures/fig0-0_工作流地圖_母圖.svg)

後面的章會直接用前面章建好的東西。每章開頭有一欄「進來之前，你要能」，那是能力層的檢查，不是材料清單。

| | 章 | 你在這一章實際做出什麼 |
|---|---|---|
| 1 | [先把現場搭起來](chapters/01-setup.md) | 一個真的知識庫、一則決策日誌 |
| 2 | [第一份文獻筆記，以及它騙了你](chapters/02-first-note.md) | 一份七欄筆記、你親手抓到的第一筆假引用，以及一條從書目庫到筆記的流程 |
| 3 | [把重複的做法固定下來](chapters/03-skills.md) | 你自己的第一個技能檔，含一條你吃過虧才加上去的規則 |
| 4 | [研究構想與文獻蒐集](chapters/04-research-question.md) | 一個查得動的研究問題，加上標好驗證層級的文獻 |
| 5 | [查證與綜整](chapters/05-verification.md) | 一句你敢寫進論文的引用，以及從二十篇筆記長出的一個論點 |
| 6 | [分析與撰寫](chapters/06-analysis-writing.md) | 一段你講得出責任邊界的分析，加上初稿 |
| 7 | [修稿、投稿、審查與誠信收束](chapters/07-revision-integrity.md) | 一份過了五角色自審的稿子，以及你自己的誠信框架 |

這張地圖會在每一章章末再出現一次，亮起那一章教的位置。

## 快速開始

| 你的狀況 | 從哪裡進去 |
|---|---|
| 只想試一下 | [第 1 章 1.1](chapters/01-setup.md)。五分鐘之內會有一個真的產出 |
| 打算認真走一遍 | 先讀 [怎麼用這本書](docs/HOW_TO_USE.md) |
| 手上已經卡住了 | [症狀導航](docs/SYMPTOM_INDEX.md)。找一句最像你現在處境的話 |
| 想先看成品長什麼樣 | [附錄 J](appendix/J-a-grown-skill.md)。一份用了幾個月的技能檔全文 |
| 讀了很多篇，還是不知道自己的研究該怎麼設計 | [第 4 章 4.6](chapters/04-research-question.md) 與 [附錄 L](appendix/L-reading-design.md) |
| 要拿去開課 | [七週課綱](syllabus/seven-week-syllabus.md) |

**這本書假設你**會用電腦但沒寫過程式，而且手上有一個正在進行的研究。第二條比較重要——每一章都要你拿自己的東西來做。

**它綁定 Obsidian。** 工具中立的寫法會讓這本書變得沒辦法用。原理適用於其他筆記工具，操作細節你要自己翻譯。

## ⚠️ 已知缺口

| 缺口 | 狀況 |

| **附錄 A 與 K 不寫介面步驟** | 只寫「裝好了長什麼樣」。逐步手冊寫完那一刻就開始壞掉，而且壞掉不會通知你 |
