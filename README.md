## 先確認一件事：下面這五件，你遇過幾件？

> **一、文獻是個無底洞。**
> 第一天搜到四十篇，第五天發現有一整條你完全沒注意到的脈絡，下面又有八十篇。
> 最後停下來的理由不是「讀夠了」，是「沒時間了」。
>
> **二、寫到一半失去方向。**
> 筆記做了三十份，每一份都很紮實。然後你打開空白文件，游標閃爍，寫不出第一句。
> 你以為是讀得不夠，回頭再讀五篇——情況一模一樣。
>
> **三、引用焦慮。**
> 改到第七稿，你已經記不清第三頁那筆引用是哪來的。要查的有六十幾筆，截止日在後天。
>
> **四、沒有人幫你審。**
> 你希望有人在送出去之前看一眼。但指導教授很忙，同儕在趕自己的稿，
> 而你看這份稿子已經看到什麼都看不出來。
>
> **五、格式地獄。**
> 投稿前一晚你在改參考文獻的標點。這件事跟你的研究品質毫無關係，
> 但它會花掉你三個小時，而且下一篇還要再來一次。

這五件看起來是五個問題，其實有同一個根源：**學術工作的流程太長、太碎、太孤獨。**

太長，所以你在第八步已經忘記第二步做過什麼決定。太碎，所以每一段之間都有摩擦成本，
而摩擦成本不會出現在任何一份研究計畫的時程表裡。太孤獨，所以沒有人在你需要的那一刻幫你看一眼。

**這本書處理的就是這三件事。**

## 但它不是一本「AI 有哪些功能」的書

整本書只有一個判準，七章各用一種方式回答它：

<div align="center">

### 「如果它做錯了，我看得出來嗎？」

</div>

這句話決定了三件事：**什麼可以交出去、什麼一定要自己做、以及交出去之後要在哪裡設關卡。**

所以這本書會花很多篇幅講它**不能**做什麼、你**會**在哪裡被騙、
以及一份看起來完整的產出可以錯得多安靜。第 2 章甚至有一節要求你
**先讓它騙你一次，親手抓到那一筆之後才准往下讀**——
因為解釋放在你親眼看到之前讀，效果會少一半。

## 七章是一條工作流，不是七個主題

![全書工作流地圖](resources/figures/fig0-0_工作流地圖_母圖.svg)

後面的章會直接用前面章建好的東西。每章開頭有一欄 **「進來之前，你要能」**——
那是能力層的檢查，不是材料清單。

| | 章 | 你在這一章實際做出什麼 |
|---|---|---|
| 1 | [先把現場搭起來](chapters/01-setup.md) | 一個真的知識庫、一則決策日誌，**第一天就有東西留下來** |
| 2 | [第一份文獻筆記，以及它騙了你](chapters/02-first-note.md) | 一份七欄筆記，加上你親手抓到的第一筆假引用 |
| 3 | [把重複的做法固定下來](chapters/03-skills.md) | 你自己的第一個技能檔，**含一條你吃過虧才加上去的規則** |
| 4 | [研究構想與文獻蒐集](chapters/04-research-question.md) | 一個查得動的研究問題，加上標好驗證層級的文獻 |
| 5 | [查證與綜整](chapters/05-verification.md) | 一句你敢寫進論文的引用，以及從二十篇筆記長出的一個論點 |
| 6 | [分析與撰寫](chapters/06-analysis-writing.md) | 一段你講得出責任邊界的分析，加上初稿 |
| 7 | [修稿、投稿、審查與誠信收束](chapters/07-revision-integrity.md) | 一份過了五角色自審的稿子，以及你自己的誠信框架 |

> 這張地圖會在每一章章末再出現一次，**亮起那一章教的位置**。七章讀完，整張圖就全部亮起來。

## 快速開始

| 你的狀況 | 從哪裡進去 |
|---|---|
| **只想試一下** | [第 1 章 1.1](chapters/01-setup.md)。五分鐘之內會有一個真的產出，不是示範 |
| **打算認真走一遍** | 先讀 [怎麼用這本書](docs/HOW_TO_USE.md)。那一頁講為什麼有一種讀法會讓你讀完之後在自己的研究上卡住 |
| **手上已經卡住了** | [症狀導航](docs/SYMPTOM_INDEX.md)。找一句最像你現在處境的話，翻過去 |
| **要拿去開課** | [七週課綱](syllabus/seven-week-syllabus.md)，正文裡標〔課堂〕的方框就是教案 |

**這本書假設你**：會用電腦但沒寫過程式；**手上有一個正在進行的研究**。
第二條比較重要——每一章都要你拿自己的東西來做，走過場的練習學不到判斷。

**它綁定 Obsidian。** 這是刻意的：工具中立的寫法會讓這本書變得沒辦法用。
原理全部適用於其他筆記工具，操作細節你要自己翻譯。

## ⚠️ 已知缺口

這本書在教「查了沒找到不等於查不到」，所以它也該把自己缺的東西講在門口。

| 缺口 | 狀況 |
|---|---|
| **附錄 A 刻意不寫介面步驟** | 它是驗收清單不是逐步手冊：只寫「裝好了長什麼樣」，不寫點哪個按鈕。⚠️ 理由是逐步手冊寫完那一刻就開始壞掉，而且壞掉不會通知你 |
| **介面步驟會過期** | 按鈕會換位置、功能會改名。書裡把原理與版本細節分開放，原理不過期 |
| **部分引用未經全文驗證** | 凡此類皆在該處標明驗證層級，不含糊帶過。⚠️ 這是本書的規矩，作者自己也受它管 |
| **在地規範層只寫「來源存在」** | 國科會與教育部的條文請自己開一次，書裡不摘要——那些會改 |
| **附錄 H 會過期** | 詞例層會，判準層不會。⚠️ **你照著掃卻掃不到東西，不代表稿子乾淨，代表清單該更新了** |

發現錯誤或過期內容，歡迎開 issue。
