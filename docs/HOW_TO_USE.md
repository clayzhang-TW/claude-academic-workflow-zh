# 怎麼用這本書

> 這一頁抽自本書前言。**如果你跳過它**，你會把這本書當參考書讀完，
> 然後在自己的研究上卡住。

## 兩種讀法，差別比你想的大

這本書裡有十八個〔教你的 Claude 建這個〕框，加上十八段可以直接複製的提示詞。它們長得像範本。**它們其實是完整解答。**

所以有一種讀法會這樣進行：讀到那個框，複製，貼進去，跑出東西來，覺得順利，往下讀。七章讀完，一路都沒有卡住過。

然後你回到自己的研究，卡住了。

因為那三十六段裡的每一段，都是某個人做完一連串判斷之後的**結果**。你複製到的是結果，不是判斷。而這本書從頭到尾在講的，就是那些判斷。

這不是我臨時想到的說法。書裡有兩個地方已經寫過同一句話。[第 4 章](../chapters/04-research-question.md)講建工具、[第 6 章](../chapters/06-analysis-writing.md)講寫作模式，兩處都說先自己寫一版，再打開參考版對照。那時候那是給那兩節的建議。現在我把它升級成整本書的讀法。

**被動讀法**

照著讀、照著貼、確認跑得起來。七章的自學閱讀時間加起來大約**八小時**。

適合三種人：你之前就做過這條工作流，想看我怎麼寫的；你在找某個特定問題的答案，不打算從頭讀；你是要拿這本書開課的教師，得先快速看完全書再挑題目。

**主動讀法**

同一個框，順序倒過來：**先看它要解決什麼問題，蓋住答案，自己寫一版，再打開對照。** 不一樣的地方就是你這次真正學到的東西。

七章走完大約**二十五到三十小時**。是被動讀法的三到四倍。

那個差額不是浪費。它就是「卡住，然後自己修通」的時間，而那正是這本書想教的能力唯一的取得方式。你不會因為看過別人修通而學會修通。

**跑通了不等於學會了。** 跑通代表那段字有效。學會代表你講得出它為什麼要那樣寫、以及拿掉其中一句會出什麼事。

**每一章讀完，問自己三題**

1. **為什麼是這樣**——這一章教的做法，為什麼是這個順序、這幾個欄位、這個非停不可的地方？換一種做會怎樣？
2. **拿掉會怎樣**——把其中一步刪掉（不查證、不留紀錄、不標驗證層級），什麼時候會出事？出事的時候你看得出來嗎？
3. **拿去投稿還缺什麼**——這一章做出來的東西，離「可以送出去」還差哪幾件？

三題答得出來，這一章你學會了。答不出來，你只是讀過。這三題沒有標準答案，也不會有人來收。它們唯一的用途是讓你誠實。

**如果你時間不夠**

不必七章都走主動讀法。選兩章，其餘被動過。

我的建議是**[第 3 章](../chapters/03-skills.md)和[第 5 章](../chapters/05-verification.md)**。[第 3 章](../chapters/03-skills.md)是你唯一會帶走的東西。課上完、書闔上之後，留在你電腦裡的是那幾個技能檔。[第 5 章](../chapters/05-verification.md)是出錯代價最高的地方，而且那種錯不會在當下顯示出來。

## 卡住的時候

會卡住是正常的。主動讀法的整個設計就是要讓你卡住。

但「卡住」跟「卡在同一個地方兩小時」是兩件事。下面這個順序照著走：

1. **回頭重讀那一節的〈帶走這一節〉。** 多數的卡住來自漏看一個關鍵設計，而那個設計通常就寫在那四五行裡。
2. **確認你卡的是判斷還是操作。** 判斷卡住（不知道該不該這樣做）繼續往下走；操作卡住（找不到那個按鈕）直接翻[附錄 A](../appendix/A-setup.md)，或者換個方式達成同樣的事—— 這本書關於介面的每一句話都會過期，見下一節。
3. **卡二十分鐘是健康的。卡一小時也是。** 這個階段不要打開書上的答案。
4. **超過一小時，打開書上那一版，逐句比對你寫的。** 找出差在哪裡、以及為什麼那個差異會讓結果不同。
5. **看完之後，把書蓋起來，自己重寫一遍。**

**唯一不要做的事：看完答案，覺得「喔原來如此」，然後直接往下讀。**

那個「原來如此」的感覺很可靠。它可靠地讓你以為你會了。你會的是**看得懂**，那跟寫得出來中間還隔著一次動手。
