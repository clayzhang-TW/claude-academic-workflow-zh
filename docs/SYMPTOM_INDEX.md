# 症狀導航

> 這一頁不是給你從頭讀的。詞彙表回答「這個詞是什麼意思」，這一頁回答另一個問題： **「我現在遇到這個狀況，該翻哪裡？」** 用法：在下面找一句最像你現在處境的話，翻過去。找不到就去看詞彙表，或直接翻〈踩坑清單〉。那一頁收的是**已經出事之後**的樣子。

## 三、我不知道要查什麼，或者查不到

- **我有興趣，但講不出一個具體的研究問題** → **[4.1](../chapters/04-research-question.md#41-從模糊的興趣到一個查得動的問題)** 從模糊的興趣到一個查得動的問題
- **我不知道這個題目值不值得做** → **[4.1](../chapters/04-research-question.md#41-從模糊的興趣到一個查得動的問題)**〈五維度評分與三角色對抗〉
- **我不知道該用量化還是質性** → **[4.1](../chapters/04-research-question.md#41-從模糊的興趣到一個查得動的問題)** 三取向、四世界觀
- **搜尋回來是空的，我想寫「這個領域沒有人做過」** → ⚠️ **[4.3](../chapters/04-research-question.md#43-文獻工作的三個瓶頸)**〈「查了沒找到」不等於「查不到」〉。**寫下去之前一定要看這一節**
- **這篇有付費牆，我拿不到** → **[4.3](../chapters/04-research-question.md#43-文獻工作的三個瓶頸)**〈付費牆不等於你拿不到〉
- **兩個資料庫都查到這一篇，這樣算兩個佐證嗎** → **[4.3](../chapters/04-research-question.md#43-文獻工作的三個瓶頸)**〈重複命中不是獨立佐證〉
- **這篇被引很多次，是不是就很可靠** → **[4.3](../chapters/04-research-question.md#43-文獻工作的三個瓶頸)**〈被引數之外〉；被引數不可跨資料庫互比
- **我不知道這一筆能不能拿來撐我的主張** → **[4.5](../chapters/04-research-question.md#45-書目管理層讓機械工作歸機械)** 驗證層級

- **「我讀了很多篇，但還是不知道自己的研究該怎麼設計」** → **[4.6](../chapters/04-research-question.md#46-這篇論文為什麼這樣做)** 這篇論文為什麼這樣做；完整清單見**[附錄 L](../appendix/L-reading-design.md)**

- **「審查者問我怎麼排除某個替代解釋，我答不出來」** → **[4.6](../chapters/04-research-question.md#46-這篇論文為什麼這樣做)** 第二題。⚠️ 那一題就是研究設計本身，而且它會在送審時原封不動回來

## 找不到你的狀況？

三個地方可以試：

1. **〈詞彙表〉**——如果你卡的是一個詞
2. **〈踩坑清單〉**——如果你已經出事了，那一頁按「事故長什麼樣」分組
3. **前言〈卡住的時候〉**——如果你卡的不是內容，是不知道還要不要繼續卡

如果三個地方都沒有，那可能是這本書真的沒寫。**這種情況請當成本書的缺口，不要當成你的問題**。書裡明講不涵蓋的東西不只一處，[第 4 章](../chapters/04-research-question.md)的研究設計只教取向不教執行，[第 6 章](../chapters/06-analysis-writing.md)的統計只教協作模式不教方法本身。
