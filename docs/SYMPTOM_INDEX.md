# 症狀導航

> 這一頁不是給你從頭讀的。詞彙表回答「這個詞是什麼意思」，這一頁回答另一個問題： **「我現在遇到這個狀況，該翻哪裡？」** 用法：在下面找一句最像你現在處境的話，翻過去。找不到就去看詞彙表，或直接翻〈踩坑清單〉。那一頁收的是**已經出事之後**的樣子。

---

## 一、剛開始的時候

- **我還沒開始，不知道第一步要做什麼** → **1.1** 五分鐘之內先讓它做一件真的事
- **我上次跟它討論的東西，現在找不回來了** → **1.2** 你剛才那段對話，明天就不見了
- **我有一堆資料夾，但每次都找不到我要的那份** → **1.3** 建你的現場（連結、別名、反向連結）
- **我不知道 Chat、Projects、Code 這些差在哪，該用哪個** → **1.4** 一個 Claude，四個入口
- **我想把逐字稿放進去，但不確定這樣安不安全** → **1.3**〈什麼不要放進來〉＋ 7.4 資料保護
- **按鈕位置跟書上寫的不一樣** → **附錄 A**；找不到就回頭看那一節在講什麼原理，再在新介面找對應位置

---

## 二、它給我的東西不對

- **它給我的參考文獻，我查不到** → **2.4** 三種型態；5.1 四步核實
- **那篇論文是真的，但它沒有說我以為它說的話** → **5.1**〈還有第零步：先確認那句話真的在那裡〉
- **作者名字有一個對不上，其他都對** → **2.4** 第三型：局部竄改。⚠️ **這一型最難抓**
- **它寫得很流暢，但我說不上來哪裡怪** → **2.3** 它在做的事是接龍
- **它給我一個數字，看起來很精確（例如 .89）** → **2.4**〈虛假精確的數字〉
- **我覺得它在瞎掰，但我沒有證據** → **2.2** 現在，讓它騙你一次。先親手抓到一筆，再往下讀
- **它前面明明答應過的限制，後面突然不遵守了** → **3.3** 為什麼你的對話會愈用愈鈍
- **同一個問題，它今天的答案跟上週不一樣** → **1.2** 兩種記憶；3.3 上下文視窗

---

## 三、我不知道要查什麼，或者查不到

- **我有興趣，但講不出一個具體的研究問題** → **4.1** 從模糊的興趣到一個查得動的問題
- **我不知道這個題目值不值得做** → **4.1**〈五維度評分與三角色對抗〉
- **我不知道該用量化還是質性** → **4.1** 三取向、四世界觀
- **搜尋回來是空的，我想寫「這個領域沒有人做過」** → ⚠️ **4.3**〈「查了沒找到」不等於「查不到」〉。**寫下去之前一定要看這一節**
- **這篇有付費牆，我拿不到** → **4.3**〈付費牆不等於你拿不到〉
- **兩個資料庫都查到這一篇，這樣算兩個佐證嗎** → **4.3**〈重複命中不是獨立佐證〉
- **這篇被引很多次，是不是就很可靠** → **4.3**〈被引數之外〉；被引數不可跨資料庫互比
- **我不知道這一筆能不能拿來撐我的主張** → **4.5** 驗證層級

---

## 四、東西太多，理不出來

- **我有二十篇筆記，但寫不出一段話** → **5.3** 從二十篇筆記到一個論點
- **我的筆記越存越多，但從來沒有再打開過** → **1.3**〈殭屍筆記〉；4.4 四種筆記
- **我想到的東西寫在某篇論文的筆記裡，後來就找不到了** → **4.4**〈把想法寫進來源筆記裡〉
- **我不知道這一篇該做哪一種筆記** → **4.4** 一篇論文可能觸發什麼
- **我不確定這件事該不該交給它做** → **4.2** 該不該交給它（風險判準 2×2）
- **每次都要重打同一段話** → **3.1** 最小的技能：一個檔案，五段
- **我建了技能檔，但它好像沒什麼用** → **3.5** 讓它長大。沒跑過真實任務的技能檔只是被搬家的提示詞

---

## 五、要動筆了

- **我不知道該讓它寫到什麼程度** → **6.3** 寫作模式鏈
- **我遇到一個沒學過的統計方法** → **6.2** 當你遇到不會的方法
- **它給我的 R 程式跑得動，但我不確定對不對** → **6.1** 統計輔助的責任邊界
- **統計軟體有警告，可是結果看起來很正常** → ⚠️ **6.1**；〈踩坑清單〉坑 6
- **我的稿子讀起來很像 AI 寫的** → **7.1** 修稿三輪；附錄 H 中文 AI 腔清單
- **我想知道自己原本的寫作習慣長什麼樣** → **附錄 G** 寫作聲紋
- **我照著 AI 腔清單改，結果把該有的學術寫法也改掉了** → ⚠️ **附錄 H-7** 誤殺防護。**動到量表題幹會讓既有效度證據失效**

---

## 六、要送出去了

- **我覺得寫完了，但不知道還缺什麼** → **7.2** 投稿前自己審一遍；附錄 I 完整檢查表
- **我不知道自己的主張有沒有寫得太滿** → **附錄 I-4** 宣稱—證據落差對照表
- **限制那一節我不知道怎麼寫** → **附錄 I-5** 限制陳述的主詞
- **審查意見回來了，我不知道從哪裡開始** → **7.3** 回應審查意見
- **我改了一個地方，不知道會不會影響別的地方** → **7.3**〈爆炸半徑檢查〉
- **我改完了，要不要再審一次** → ⚠️ **7.2**〈改完再跑一次〉。**「看過了決定不改」跟「根本沒看到」在稿子上長得一模一樣**
- **期刊要我聲明有沒有用 AI，我不知道怎麼寫** → **附錄 D** 使用聲明範本
- **我不確定這樣算不算抄襲** → **7.4** 誠信的完整框架；⚠️ **學術倫理的抄襲範圍比著作權侵權寬**
- **我不知道要不要揭露，也不知道揭露到什麼程度** → **7.4**；⚠️ 規則模糊的時候能保護你的只有紀錄。**當下就標日期、截圖、另存**

## 七、教這門課

- **我要開課，時間怎麼配** → 各章〔課堂〕框；七週課綱
- **學生第一週就會卡在哪裡** → **1.7** 動手實作的〔課堂〕框
- **我要訂課堂上的 AI 使用政策** → **附錄 E** 課堂政策；E-2.5 機制優先於規定
- **我要出作業，但不知道怎麼評「有沒有自己判斷」** → **附錄 E** 理由欄對照表；評量採「檢核＋修訂定稿」兩段式

## 找不到你的狀況？

三個地方可以試：

1. **〈詞彙表〉**——如果你卡的是一個詞
2. **〈踩坑清單〉**——如果你已經出事了，那一頁按「事故長什麼樣」分組
3. **前言〈卡住的時候〉**——如果你卡的不是內容，是不知道還要不要繼續卡

如果三個地方都沒有，那可能是這本書真的沒寫。**這種情況請當成本書的缺口，不要當成你的問題**。書裡明講不涵蓋的東西不只一處，第 4 章的研究設計只教取向不教執行，第 6 章的統計只教協作模式不教方法本身。
